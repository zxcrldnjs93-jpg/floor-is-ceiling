# v0.3.5 글자 색 대비

기본 라이트 화면의 글자·배경 쌍을 `site/tokens.css`, `site/styles/site.css`와 장면 마크업에서 확인했다. WCAG AA의 일반 글자 기준은 4.5:1이고, 큰 글자는 3:1이다. 큰 글자는 보통 굵기 24 CSS px 이상 또는 굵은 글자 약 18.67 CSS px 이상이다. 판정은 반올림 전 비율로 한다.

```sh
qa/run.sh --v03 --static-only --contrast qa/contrast-pairs.json site/dist/
```

## 디자인 전달 목록

- `.lift .dots`의 비현재 층 글자 `#6E4334`와 `--c-led-panel` 배경 `#161A1E` 조합 한 쌍이 미달이다. 같은 글자가 낮은 화면에서는 17px이므로 변경 후 4.5:1을 충족해야 한다. 예를 들어 글자 `#9B8276`는 현재 배경에서 4.871:1이다. 빌드에 새 색을 적용한 뒤 `qa/contrast-pairs.json`의 두 행을 맞춰 다시 실행한다.
